# iPhone のショートカットで、クリップボードの文字を PC へ送る

Safari のページを開かずに、ワンタップで送る組み方。HTTP のページはブラウザから
クリップボードを読めない（iOS の仕様）ため、「長押し → ペースト」が要る。
ショートカットアプリは読めるので、こちらなら長押しもページを開く手間も要らない。

## 組み方（iPhone の「ショートカット」アプリ。アクション3つ）

1. 「＋」で新規ショートカットを作る。名前は「PCへ送る」など。
2. アクション「**クリップボードを取得**」を追加する。
3. アクション「**入力からテキストを取得**」を追加し、入力に「クリップボード」を渡す。
   これを挟まないと、クリップボードが書式付き（RTF）のまま送られ、
   PC に `{tf1nsi…` のような文字が出る（実機で確認済み）。
4. アクション「**URLの内容を取得**」を追加し、次のとおり設定する。
   - URL（入力欄に、文字列として打つ。クリップボードの変数が混ざらないこと）: `http://<PC名>.local:8000/api/text`
     （PC名は、PC で `http://localhost:8000/setup` を開いた案内ページに出る接続先と同じ）
   - 「詳細」を開く。
   - 方法: **POST**
   - ヘッダ: `X-LanDrop-Token` ＝ トークン
     （案内ページの QR・トークン欄に出ている値。家族以外に見せない）
   - 本文を要求: **ファイル**。ファイルに、手順3の「**テキスト**」を渡す
     （欄をタップ→「変数を選択」→「テキスト」）。
     本文がそのままテキストとして受け付けられる（`text/plain`）。
5. 任意：最後に「通知を表示」を足して、結果（「URLの内容」）を出すと、送れたか分かる。

## 呼び出し方（どれか）

- ホーム画面に追加（共有ボタン →「ホーム画面に追加」）：1タップ。
- 背面タップ：設定 → アクセシビリティ → タッチ → 背面タップ → ダブルタップ に割り当てる。
  コピーして、背面を2回叩けば送れる。
- 共有シートに出す：ショートカットの詳細で「共有シートに表示」をオンにすると、
  Safari の共有ボタンから、開いているページの URL をそのまま送れる。
  その場合は手順2のクリップボードの代わりに「共有シートの入力」を渡す。
- アクションボタンのメニューに入れる：実機で動作確認済み（コピー→ボタン→選択）。

## 確認

- PC のトレイ（LAN Drop）に「届きました」の動作が出る（設定により、右下のプレビュー窓）。
- 401 が返る場合はトークンの違い。400「本文が空です」はクリップボードが空。
- PC 側の取り込みは `POST /api/text`（本文がそのままテキスト、または JSON `{"text": "..."}`）。
