# [Claude依頼] 新機能の案出し 第1回：職場のPCで「明日から便利！」になる機能を5つ考える

## 目的
陽太さんから「Claude と Muse の二人で、私が思いつかないような tray-tools の役立ち機能を議論して決めてほしい。
**職場環境で明日から使えて、便利！ってなるもの**がベスト」と頼まれた。全4回の往復で進める：

1. **案出し（今回）**：Muse と Claude が別々に5案ずつ出す（Claude の案は伏せてあり、Muse の案が届いてから並べる。先に見せると引っ張られるため）
2. 相互批評：互いの案に突っ込む
3. 絞り込み：上位3案に点数と理由
4. 簡単な仕様：画面イメージ・使う場面・実装規模

最後に陽太さんが3案から選ぶ。**今回は案を出すだけで、コードは一切書かない。**

## 前提（職場のPC）
README.md・AGENTS.md・CLAUDE.md に書いてあることに加えて：
- Windows 11 の業務用ノートPC。ノート画面がプライマリ、正面の拡張ディスプレイがセカンダリ（トレイはノート側にしか出ない）
- Microsoft 365 中心：Outlook・Teams・M365 Copilot（`M365Copilot.exe`）・Edge・エクスプローラー・Office
- **Claude Code は無い**。管理者権限は無い前提。プロキシがあり、PC から外部のサービスへ直接つなげない（Pushover も使えない）
- **データを PC の外へ持ち出せない**（だから診断は QR で読み上げる作りになっている）
- EDR がある。グローバルホットキー・入力の自動生成は慎重に（README「会社のPCで使う場合の注意」）
- 更新は ZIP を Edge で落として当てる（git の無い PC でも動く作り）
- 在宅勤務が中心。会議は Teams

## やること
1. README.md を中心に、**今ある機能を把握する**（重ねて提案しないため）。特に：画面アイコンのメニュー構成、Rapture（画面キャプチャ付箋）、定型文、クリップボードの書式落とし、Teams の一人会議、画面ミラー、プレゼン支援、タスクバーウィジェット、Copilot 状態監視、スリープ抑止
2. **新しい機能の案を5つ**出す。1案ごとに：
   - **名前**（短く）
   - **どんな困りごとを解くか**（職場のどんな場面で「便利！」となるか。1〜3行）
   - **使い方**（トレイメニュー／ホットキー／自動、など。何をすると何が起きるか）
   - **既存機能との関係**（どの機能の延長か・新規か。重なりが無いことの説明）
   - **実装の見込み**（使う仕組み：COM・UIA・Win32・Qt など、規模の目安 小/中/大、職場のPCの制約で詰まりそうな点）
   - **「明日から使える」度**（設定・準備なしで使えるか）
3. 5案のうち、Muse の**イチオシ1つ**とその理由
4. 発想の幅を出すため、**5案のうち少なくとも2つは「既存機能の延長ではない」もの**にする

## 判断の物差し（参考）
- 毎日何度も起きる小さな面倒を消すもの ＞ たまにしか使わない大きな機能
- 設定なしで初日から効くもの ＞ 準備が要るもの
- 職場の制約（持ち出し禁止・管理者権限なし・外部接続なし・EDR）の中で動くこと
- リポジトリの決まり：**トレイアイコンを増やさない／新しい IPC ポートを作らない／外へデータを送らない**
