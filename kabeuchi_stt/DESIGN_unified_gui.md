# 統合 GUI（S3「3行窓」＋F3「1列＋引き出し」）設計メモ

版 `20261123-02`（第1版。「一旦つくってみる」段階）。画面案は `stage0\mockup_gui_unify.html`（S3 と F3 の節）、比較の経緯は `stage0\compare_modes.html`。
陽太さんの方針: 「対話モードの使い勝手をベースに、壁打ちの良さを取り入れ、ほぼ同じ GUI に統合」。小さめ系は S3、フル機能系は F3。

## 1. 方針

- **UI 層だけを組み替える。** AI対話のロジック層（`dialogue_controller` / `dialogue_session` / `dialogue_buffer` / 配達）と、壁打ちの録音・清書・履歴は、そのまま使う。
- **classic（従来の左右2ペイン）は消さない。** 設定 `ui_layout` = `unified`（既定）/ `classic`。切り替えは次回起動（設定ダイアログ「画面の種類」）。classic のコードは変更していない（下記の差し込み点だけ）。
- **機能は削らず「移す」。** 履歴・検索・再生・清書のやり直し・削除、専門用語、置換辞書、Copilot プロンプトは、メイン窓がすでに持っている部品を**引き出しへ付け替える**（作り直さない）。だから検索・再生・保存・辞書の反映のロジックは従来のまま動く。
- **自動配達しない。** 下書きを、利用者の操作なしに宛先へ入れない。無音による自動確定は無い（既存テストが保証）。この GUI でも、モード切替・引き出しの開閉・下書きを広げる操作は配達しない（テストあり）。

## 2. 部品の分割

| ファイル | 役割 |
|---|---|
| `ui_unified_logic.py` | 純関数（Qt なし）。マイク状態チップの状態判定（8状態＋判定前の「確認中」）・録音／確定／一時停止ボタンのモード別の文言・経過時間・壁打ちの下書き（タイムライン→波形／黄色）への写し方・「直近3行」の高さ |
| `ui_mic_chip.py` | `MicChip`（固定サイズの角丸チップ。文言と色だけ変わる）、`ChipPopup`（押したときの詳細。窓の中に重ねる子ウィジェット） |
| `ui_unified.py` | `UnifiedPanel`（`DialoguePanel` を継承。下書き欄＋宛先・送信までする＋未配達の行＋確定ボタン＋通知の1行）、`UnifiedView`（窓の中身。上段＋パネル＋引き出し） |
| `ui_drawer.py` | `Drawer`（履歴／用語・置換／Copilot／設定の4タブ。メイン窓の既存部品を付け替える） |
| `ui_main.py`（差し込みだけ） | `_build_unified()`、録音・一時停止の振り分け、geometry の別キー、設定ダイアログの「画面の種類」、清書完了時のコピー |

`ui_main.py` に足したのは、統合 GUI の組み立てと窓まわり（約150行）だけ。画面の中身は新規ファイルに分けた。

## 3. classic との切り替え

`MainWindow.__init__` が `ui_layout` を読む（`classic` 以外は unified）。

- **classic**: 従来どおり（`self.unified is None`）。`ui_dialogue.DialoguePanel`・タブ・タイムライン。コードの経路は変えていない。
- **unified**: 従来の画面の部品（タブ）は**捨てずに隠して持つ**（`_classic_holder`）。録音・清書・履歴・辞書・マイク診断の処理が、従来の部品（`btn_rec`・`lst_hist`・`tbl`…）を介して動くため。履歴・辞書の部品だけは引き出しへ移る。
  中央は `UnifiedView`。対話パネルは `UnifiedPanel`（常に作る。`dialogue.enabled` が OFF のときは、モード切替の［AI対話］が無効になるだけ）。

## 4. 既存のシグナル・ロジックの再利用

- `UnifiedPanel(DialoguePanel)`: 下書きとバッファの同期・確定・配達・未配達・宛先・通知はすべて親のもの。見た目の組み立て（`_build`）を差し替え、ボタン類を親の `refresh()` から切り離すために、親へフックを3つ足した（`_refresh_session_buttons` / `_apply_commit_button`、起動時の通知の条件）。親の挙動は変えていない（既存の `test_gui_dialogue` 61本は無変更で通る）。
- `UnifiedView.refresh()` は、`MainWindow._tick`（100ms）から呼ばれ、状態を読むだけ（録音中か・一時停止か・経過時間・メーター・マイクの指摘）。状態の持ち主は従来どおり `Session`・`DialogueSession`・`MainWindow._issues`。
- 録音ボタンは1つ。`MainWindow.toggle_record()`（ボタン・ホットキー・トレイ共通）が `UnifiedView.rec_pressed()` へ振り分ける: 壁打ち = 録音開始／停止（停止すると清書してコピー）、AI対話 = セッション開始／終了。`toggle_pause()` も同様（壁打ち = 一時停止／再開、AI対話 = ［保留］）。
- 通知の1行: `QStatusBar.messageChanged` を `UnifiedPanel.set_notice` へつなぎ、ステータスバーは隠す（従来の `showMessage` がそのまま下書き欄の下の1行に出る）。
- COM はメインプロセスで使わない（配達は従来どおりワーカー経由）。

## 5. モードごとの動き

| | 壁打ち（wall） | AI対話（dialogue） |
|---|---|---|
| 録音ボタン | 録音開始 / 停止（停止＝停止→清書キュー→**終わったら全文をクリップボードへコピー**。`auto_copy` の設定に関わらず） | 録音（＝セッション開始）/ 停止（＝セッション終了。残りがあれば従来の確認） |
| 一時停止ボタン | 一時停止／再開（同じ WAV に続ける） | ［保留］（取り込みを止める）と統合 |
| 下書き欄 | 録音中・清書待ち: 波形→黄色（仮認識。発話ごと）、**読み取り専用**。清書が終わると白の全文になり**直せる** | 従来どおり（波形→黄色→白。キーボードで直せる。カーソル・選択を認識の更新で動かさない保護も維持） |
| 主ボタン | 「清書してコピー」: 録音中なら止めて清書→コピー、清書後は**いまの下書き（直した内容）をコピー** | 「確定して届ける」（Ctrl+Enter・ヘッドセット単押し・ホットキーと同じ） |
| 宛先・送信までする | 隠れる | 出る |
| 全部消す | 画面の下書きを消す（履歴には残る） | 従来どおり（バッファの下書きを破棄） |

モード切替は上段のトグル。録音中・セッション中・終了処理中は切り替えられない（通知で知らせる）。最後のモードは `unified_mode` に記憶。

### 宛先「なし」（クリップボードへコピー）
宛先のコンボの末尾の項目（`dialogue.dest_clipboard`）。確定すると、入力欄へは何もせず（窓も探さない）、クリップボードへコピーして「配達済み」として扱う（`DialogueController._deliver` が `clipboard_copy` イベントを出して `{"status": "delivered", "stage": "clipboard"}` を返す。クリップボードの書き込みは UI スレッド）。実際の宛先を選ぶと自動で OFF。未選択・「なし」のときは宛先の警告を出さない。

### Copilot の前置き
宛先の名前に「copilot」を含むときだけ、前置きの行が出る。選んだプリセット（Copilot タブのもの）を、確定した内容の前に付けて届ける（`DialogueController.text_transform`）。**選ばなければ何も付けない。** 再試行でも毎回かかる。

## 6. マイク状態チップ

`ui_unified_logic.chip_state()` が、既存の判定の結果を1つの状態にまとめる（新しい判定はしない）。優先順: マイク使用中（`monitor_error`）> 未録音／一時停止中の話し声（赤いメーターと同じ条件 `meter.unrecorded`）> 音が入っていない（録音中 2 秒・待機中 3 秒）> 音量の指摘（`mic_check.Issue`: 音割れ > 小さい > ノイズ）> 入力OK。判定前（入力を開いていない・統計なし）は、画面案の8状態に無い中立の「マイク確認中」。
**サイズ不変**: 全状態の文言のうち最長のものが収まる固定サイズ（表示サイズ変更のたびに `refit()`）。状態が変わっても上段の部品の位置は動かない（テストあり）。詳細は押したときだけ（窓内の吹き出し。15秒で閉じる）。

## 7. 窓の大きさ・位置

- 新しいキー: `win_geometry_unified`（引き出しを閉じている）／`win_geometry_unified_drawer`（開いている）。classic の `win_geometry_*` は触らない（テストで確認）。
- 引き出しの開閉は `MainWindow._unified_relayout()`: いまの状態を保存し、切り替え後の状態を復元（未保存なら左上を保って幅を ±460px）。
- 既定: 閉じる＝幅400×高さ約330（直近3行）。▾で広げる＝高さ約560。引き出しを開いている間は窓が大きいので、下書きも自動で広げる（閉じれば元の状態へ）。
- 最小サイズは部品が重ならない大きさ（`UnifiedView.minimumSizeHint()`）。未配達の行・通知の折り返しなどで変わったら、tick で取り直す。

## 8. 画面案から変えた点

画面案の「時刻行（30秒ごと）」は、S3/F3 の下書きには無い（F4 のタイムライン列の案）ので、**下書きに時刻行は出さない**。壁打ちの清書の下書きは、設定どおりのすき間・句点の改行の全文。録音の日時・長さは引き出しの履歴にあり、行クリックの再生もそこ。詳細は報告に記載。
