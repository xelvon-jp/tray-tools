# kabeuchi_stt（壁打ち文字起こし）

独り言を30分ほど喋り続けて文字起こしする、ローカル完結のツール（音声は外に出さない）。版は `version.py`（例 `20261122-02`、画面タイトルにも表示）。仕様は `SPEC.md`。

- **v2（PySide6・トレイ常駐）**: `main.py`。フェーズ1（SPEC の A〜G）＋フェーズ1.5（待機中のマイク監視・一時停止・コンパクト表示 ほか）を実装。
- **v1（tkinter）**: `app.py`。v2 が実機で安定するまで残してある。

## セットアップ

```powershell
$env:PYTHONUTF8=1
python -m venv "$env:USERPROFILE\.venvs\kabeuchi-stt"
& "$env:USERPROFILE\.venvs\kabeuchi-stt\Scripts\python.exe" -m pip install -r requirements.txt
```
venv はプロジェクト外に置く。依存は faster-whisper / sounddevice / numpy / PySide6。

## 起動（v2）

```powershell
$env:PYTHONUTF8=1
$py = "$env:USERPROFILE\.venvs\kabeuchi-stt\Scripts\python.exe"
& $py main.py                       # GUI（トレイ常駐。2つ目を起動すると既存の窓が出る）
& $py main.py --hidden              # 窓を出さずトレイ常駐だけで起動
& $py main.py --no-tray             # トレイを使わない（閉じると終了）
& $py main.py --wav out\xxx.wav     # 既存WAVの清書だけやり直し（GUIなし。置換辞書は適用、履歴には載せない）
& $py main.py --wav out\xxx.wav --model medium
& $py main.py --list-devices        # 入力デバイス一覧（マイクは開かない）
```

## タスクバーにピン留めする

```powershell
$py = "$env:USERPROFILE\.venvs\kabeuchi-stt\Scripts\python.exe"
& $py make_assets.py       # アイコン（assets\kabeuchi_stt.ico/.png）。絵を変えたときだけ
& $py make_shortcut.py     # このフォルダに「壁打ち文字起こし.lnk」を作る（pythonw.exe main.py・作業フォルダ・アイコン付き）
```

1. 作った `壁打ち文字起こし.lnk` をダブルクリックで起動（黒い窓は出ない）。
2. **起動したらタスクバーのアイコンを右クリック →「タスクバーにピン留めする」**。
3. うまくいかないとき（アイコンが python のままだったり、ピン留めしたものを開くと何も起きないとき）は、2 の代わりに `壁打ち文字起こし.lnk` を右クリック →（Windows 11 は「その他のオプションを確認」）→「タスクバーにピン留めする」。
- 窓は専用の AppUserModelID（`kabeuchi.stt`）を名乗るので、python のアイコンにまとまらない。ショートカットは `.lnk` を作るだけで、デスクトップ等には作らない。リンク先の `pythonw.exe` は、`make_shortcut.py` を実行した python と同じフォルダのもの（`--python` で指定可）。

## 使い方

1. 「● 録音開始」。中央のタイムラインに30秒ごとの行が増え、**波形（青緑）→ 仮認識（オレンジ）→ 清書（白）** と置き換わる。上段に経過時間・音量メーター・マイクの状態バッジ。
2. 「■ 停止して清書」で自動的に**清書キュー**へ。清書は裏で走るので、清書中でも次の録音を始められる。終わるとトレイ通知＋全文をクリップボードへコピー（設定で OFF 可）。
3. 無音が続くと自動停止（既定 180 秒、設定で変更。0 で無効）。止め忘れ対策。
4. **マイクの指摘**: 「マイクテスト（3秒）」ボタンと、録音中・待機中の常時監視。小さすぎ／音割れ／ノイズ大／無音を、対処つきで上段のバッジと帯に出す。録音は止めない。しきい値は設定（下表）。
5. **待機中のマイク監視**（既定 ON）: 窓が**見えている間だけ**マイクを開き、録音していなくてもメーターと診断が動く（音声は保存も認識もしない）。窓を隠す・最小化する・5 分操作しないと閉じる（操作すると再び開く）。他のアプリがマイクを独占していると「マイクを使用中のため確認できません」と出る。録音開始時は同じストリームを引き継ぐ（開き直さない）。
6. **「録音していません（話しているようです）」**: 録音していないのに話し声が 1.5 秒以上続くと、帯と［録音開始］ボタンが出る（20 秒で消える。×で閉じる。60 秒は再度出ない。窓が隠れているときは出ない）。設定で OFF や間隔の変更ができる。
7. **一時停止 / 再開**: ［❚❚ 一時停止］（録音中だけ押せる）。休止中は WAV に書かず、経過時間も止まる。［▶ 再開］で同じ WAV に続く。タイムラインに「一時停止 mm:ss」の印の行が 1 行出る。トレイメニューやホットキー（`hotkey_pause`）からも操作できる。履歴・清書は 1 本のまま。
8. **無音の畳み込み**: 録音には無音も入る（時刻と文字の対応を保つため）。清書後のタイムラインでは、連続した「（発話なし）」が「無音 2:30」の 1 行にまとまる。
9. **句の区切りで改行**（清書の出力の後処理）: 区間のすき間が 3 秒以上なら必ず改行（句点がなければ「。」を補う）、2〜3 秒なら句点・？・！のあとだけ改行、2 秒未満はつなげる。**txt / md の全文 / クリップボード**に効く。履歴の元の区間（時刻つき）は無加工のまま。設定で OFF（従来の 1 区間 1 行）や秒数の変更ができる。フィラー（えーと等）は消さない。
10. **コンパクト表示**: ［コンパクト］で細長い窓（録音・一時停止・時間・メーター・マイク状態・直近の行・清書の要約だけ）。［通常］で戻る。通常/コンパクトそれぞれの位置とサイズを覚えている（画面外に出ないよう補正）。履歴・辞書はトレイから開くと通常表示に戻る。
11. **最前面**: ［最前面］（画びょうのアイコン）で他の窓より前に固定（設定に記憶）。前面化の強制はしない（アクティブにせず表示するだけ）。
12. **逐次認識の切替**: 「逐次認識」のチェックは録音中でも切り替えられる（OFF で仮の文字を止める／ON でその時点から始める。録音は止まらない）。
13. **一時停止中に話したとき**: 話し声を検出すると「一時停止中です（話していますが録音されていません）」の帯と［再開］ボタンが出る（待機中の「録音していません」と同じ仕組み・間隔・設定）。
14. **赤いメーター**: 録音していない（待機中・一時停止中）のに話しているあいだ、音量メーターが**赤**になり「● 未録音」の印が付く（録音中は緑。即時に赤、静かになって 0.5 秒で戻る）。
15. **右クリックメニュー**: 文字起こしの行（タイムライン・履歴の本文）を右クリック →「このパートをコピー」「全文コピー」（清書の出力と同じ整形）「ここから下をコピー」（選択中は「選択部分をコピー」、履歴は「ここから再生」も）。
16. **表示サイズ**: 設定の「表示サイズ」小（既定）/ 標準 / 大。再起動なしで切り替わる。
17. 右パネル:
   - **専門用語**: チップで追加/削除。`settings.json` の `hotwords` に保存され、仮認識・清書の全窓に渡る。
   - **自動置換辞書**: 「誤認識 → 正解」。編集するとその場で保存・反映。清書と仮認識の両方に適用。
   - **Copilot プロンプト**: プリセット（名前＋本文）の追加/保存/削除。「プロンプト＋文字起こしをコピー」で、プロンプトと本文を1つにしてクリップボードへ（貼るのは本人。自動入力はしない）。
18. 「履歴・検索」タブ: 録音ごとに日時・長さ・先頭の一文・モデル。全文検索（空白区切りで AND、修正後の文も対象）。選ぶと本文が開き、**行をクリックするとその位置から再生**。再生の**出力先**を選べる（「システム既定」は、再生を始めるたびに今の既定デバイスを取り直すので、TrayTools 等で既定を切り替えても追従する。選んだデバイスが無くなったら、システム既定に戻して画面で知らせる）。本文は直接編集でき「修正を保存」（元の清書は DB に残り、`_edited.txt` も隣に出す）。「直した語を辞書へ…」で差分から置換候補を登録。「WAVから清書をやり直す」「削除（ごみ箱へ）」。

## 自動置換の適用ルール

1パスのみ（置換結果は再置換しない＝無限ループなし）／同じ位置は長い誤認識を優先（「一時集計」が「集計」に勝つ）／同じ誤認識の重複は後勝ち／空の誤認識は無視。

## 設定（settings.json）

プロジェクト直下の `settings.json`（`.gitignore` 済み。個人固有の語彙が入るので共有しない）。無ければ既定値で自動生成。v1 のキー（`out_dir` `model_dir` `final_model` `live_model` `initial_prompt` `hotwords` `input_device` `live_enabled` `compute_type` `device` `live_cpu_threads` `final_cpu_threads` `vad_*` `live_max_backlog`）はそのまま。v2 で増えたもの:

| キー | 既定 | 説明 |
|---|---|---|
| `row_sec` | 30 | タイムライン1行の秒数 |
| `silence_stop_sec` | 180 | この秒数の無音で自動停止（0=無効） |
| `silence_stop_peak_dbfs` | -50 | 無音判定の下限（床より10dB以上大きい音が無い状態を無音とする） |
| `model_idle_release_sec` | 600 | モデルをメモリに保持する秒数（最後の使用から。超えたら解放） |
| `auto_copy` | true | 清書完了時に全文をクリップボードへ |
| `hotkey_record` / `hotkey_show` | 空 | グローバルホットキー（下記） |
| `mic_low_peak_dbfs` | -30 | ピークがこれ未満が続くと「小さすぎ」 |
| `mic_clip_ratio` | 0.001 | ±満杯サンプルの割合がこれ超で「音割れ」 |
| `mic_noise_floor_dbfs` | -45 | 無音時の床がこれ超で「ノイズ大」 |
| `mic_dead_peak_dbfs` | -70 | ピークがこれ未満で「音が入っていません」 |
| `mic_window_sec` | 8 | 常時監視の判定窓 |
| `idle_monitor` | true | 窓が見えている間、待機中もマイクを開いてメーター/診断を動かす（保存・認識なし） |
| `idle_monitor_timeout_sec` | 300 | 操作がこの秒数ないと待機中モニターを閉じる（0=閉じない） |
| `idle_prompt_enabled` | true | 録音していないのに話しているとき「録音していません」を出す |
| `idle_prompt_speech_sec` | 1.5 | 発話らしい音がこの秒数続いたら指摘 |
| `idle_prompt_cooldown_sec` | 60 | 指摘を出したあと、この秒数は再度出さない |
| `hotkey_pause` | 空 | 録音の一時停止/再開のホットキー（`hotkey_record` / `hotkey_show` と同じ書式） |
| `paragraph_enabled` | true | 清書の出力（txt/md/クリップボード）をすき間の長さで改行する |
| `paragraph_gap_sec` | 2.0 | このすき間以上で、直前が句点・？・！なら改行 |
| `paragraph_force_gap_sec` | 3.0 | このすき間以上なら必ず改行（句点がなければ「。」を補う） |
| `compact_mode` | false | コンパクト表示で起動する（画面のボタンで切り替えると自動で記憶） |
| `always_on_top` | false | 最前面に固定（画面のボタンで切り替えると自動で記憶） |
| `win_geometry_normal` / `win_geometry_compact` | 空 | `[x, y, w, h]`。通常/コンパクトの位置とサイズ（自動で記憶・復元。画面外ならクランプ） |
| `display_size` | small | 表示サイズ（small / standard / large）。設定ダイアログで切替（再起動不要） |
| `playback_device` | 空 | 履歴の再生出力先の id（空=システム既定）。画面のコンボで選ぶと記憶 |

画面の「設定」からは 清書/逐次モデル・マイク・無音自動停止・待機中モニターと「録音していません」・清書の改行・ホットキー・自動コピーを変更できる。

## ホットキー

`settings.json` の `hotkey_record`（録音の開始/停止）・`hotkey_pause`（一時停止/再開）・`hotkey_show`（窓の表示/非表示）か、画面の「設定」で指定。例 `Ctrl+Alt+F9`。**既定は未割り当て。** `RegisterHotKey`（ctypes）を使い、低レベルキーフックは使わない（EDR に検知されうるため）。Ctrl/Alt/Shift/Win のいずれかが必須。

**注意: Claude アプリ等の常用ショートカットと衝突しない組み合わせにすること**（過去に Ctrl+Alt+A がアーカイブと衝突した）。他アプリが使用中だと登録に失敗し、その旨のダイアログが出る。

## モデルのオフライン手置き（SSL検査環境向け）

読み込み順: ①`model_dir\<モデル名>\model.bin`（ネットに出ない）→ ②`model_dir` 内の取得済みキャッシュ → ③ダウンロード。失敗すると手順が日本語で出る。別PCで `python -c "from faster_whisper import download_model; print(download_model('small'))"` を実行し、表示されたフォルダの中身を `models\small\` へコピー（直下に `model.bin`）。目安: base 約140MB / small 約460MB / medium 約1.5GB。`models\` が OneDrive 配下だと同期されるので、気になる場合は `model_dir` をフォルダ外の絶対パスに。

## 録音が落ちても

WAV は録音中ずっとディスクへ追記され、1秒ごとにヘッダが確定する。落ちても最後の約1秒手前までは開ける。ヘッダ未確定でもファイルサイズから読めるので `--wav` で清書できる。録音スレッドは認識側（仮認識・清書）の遅れや例外から独立している。

## tray-tools への同梱

tray-tools の `kabeuchi_stt\` に入れて使う形（SPEC のフェーズ3）。tray-tools 側の手順は tray-tools の README の「壁打ち文字起こし」の節。

- コアは GUI・Qt・COM に依存しない（`recorder` `transcriber` `session` `pipeline` `finalize_queue` など）。**別プロセスで `main.py` を起動する**（Whisper の推論は CPU を使い切るので、tray-tools 本体と同居させない）。
- **トレイアイコンは増やさない**（tray-tools は通知領域のアイコンを2つに固定している）。tray-tools から起こすときは `--no-tray` を付ける。このとき窓を閉じるとプロセスが終了し、取り残されない。もう一度起こすと、2つ目は `single_instance.notify_existing()` で既存の窓に「出して」と頼んで終わる（窓は1つだけ）。
- ホットキーは `hotkey_record` などの `RegisterHotKey`。tray-tools 側のホットキー（`keyboard` ライブラリ）と同じ組み合わせにしないこと。
- 本人のデータは `%LOCALAPPDATA%\kabeuchi_stt\`。リポジトリに入れない。モデル（`models\`）・出力（`out\`）・`settings.json` も `.gitignore` で除外してある。
- venv は別（`%USERPROFILE%\.venvs\kabeuchi-stt`。faster-whisper が重いので tray-tools の venv に混ぜない）。tray-tools の `setup.py --with-whisper` が作る。
- `on_text` / `on_segment` / `on_progress` / キューのイベントは**別スレッドから呼ばれる**。Qt では Signal 経由で UI スレッドへ。
- 音声入力（SPEC の H）はフェーズ2で未実装。キー送信を伴うので実機テストは本人の立ち会いで。

## 既知の罠

- **（1.6）改行が効かない原因**: Whisper の区間は無音を区間の中に含めて連続して返す（end==次の start）ことがあるので、区間の時刻だけではすき間が見えない。清書時に WAV から無音を測って整形している（`gaps.py`）。履歴から後でテキストだけ整形し直すことはできない（無音の長さを保存していないため）。**既存の清書（1.6 より前）の txt は改行なしのまま**で、「WAVから清書をやり直す」と改行が入る。
- **（1.6）テストの再生**: `test_gui_smoke` の QMediaPlayer の `stop()` が、まれに Qt 側で固まることがある（環境依存。単体では再現しない）。`run_all.py` は、タイムアウトしたモジュールを 1 回だけ再実行する。

- **（1.5）一時停止中の仮認識**: 逐次認識は音が届かない間は区切りの無音を見られないので、一時停止の直前の発話は再開するまで確定しない（清書には影響しない）。
- **（1.5）待機中モニターと排他モード**: 他のアプリがマイクを排他で使っていると開けない（「マイクを使用中のため確認できません」。15 秒おきに再試行）。録音開始時に開けなければ従来どおり警告が出る。
- **（1.5）ピン留め**: Windows は、起動した窓のアイコンからのピン留めだと `pythonw.exe` 単体を登録することがある。その場合は `.lnk` から直接ピン留めする（上の手順）。ピン留めした `.lnk` と起動中の窓が別のアイコンに分かれる場合も、同じ理由（ショートカット側に AppUserModelID を書けない）。
- **（1.5）再生デバイス**: 「システム既定」は再生を始めるたびに取り直す。再生**中**の切替は Qt のデバイス変更通知頼み（通知が来ない環境では次の再生から反映）。
- **（1.5）整形 ON の既定**: すき間 2 秒未満の区間は同じ行につながる（従来は 1 区間 1 行）。1 区間 1 行に戻したいときは設定で OFF。

- **PyAV（av）19 と faster-whisper 1.2.1 の不整合**: mp3 等を直接渡すと `decode_audio` が落ちうる（`pip install "av<17"`）。16kHz mono の WAV と PCM16 WAV は自前で読むので影響しない。
- 逐次認識の誤変換（例: 「壁打ち」→「壁内」）は仮表示の品質。清書で直る。
- スロット内で例外が投げ切られると PySide6 はプロセスごと落ちるため、全スロットを `safe()` で包み `error.log` へ記録している。
- QMediaPlayer（Qt の FFmpeg バックエンド）は WAV を開くとき stderr にログを出す。無害。
