# LAN Drop

同じLANにいる iPhone から Windows PC へ、写真やファイルを送るための受信サーバーです。
iPhone 側にアプリを入れる必要はなく、Safari かショートカットから送れます。

- PC：FastAPI の受信サーバー（ポート 8000）。受け取ったファイルは保存フォルダへ入る
- iPhone：Safari のアップロードページ（複数選択可・進捗表示）／ iOSショートカットから POST
- 認証：トークン（合言葉）。同じLANにいる他の人は、トークンを知らない限り送れない

## 使い方

### 1. PCでサーバーを起動

起動方法は2つあります。どちらも初回だけ `.venv` を作って依存パッケージを入れるため少し時間がかかります。

- **`start_tray.bat`（ふだん使い）**：タスクトレイに常駐します（コンソール窓なし）。下の「常駐（タスクトレイ）」を参照
- **`run.bat`（動作確認・トラブル時）**：コンソールに受信ログとQRが出ます

同じポートを使うので、両方を同時には起動できません（後から起動した方は何もせず終了します）。

`run.bat` で起動すると次の表示が出ます。

```
LAN Drop 0.1.0
  設定     : ...\lan-drop\config.toml
  保存先   : C:\Users\<you>\Downloads\LanDrop
  iPhoneで : 下のQRをカメラで読む（または http://<PC名>.local:8000/#t=... を開く）
  名前で届かないとき : http://<PCのIPアドレス>:8000/#t=...
  PCで案内 : http://localhost:8000/setup
```

- 初回起動時に `config.toml` が作られ、ランダムなトークンが入ります
- **Windows ファイアウォールのダイアログ**が出たら「プライベート ネットワーク」を許可してください（パブリックは不要）
  - 家のWi-Fiが「パブリック」扱いになっていると iPhone から届きません。設定 → ネットワークとインターネット → Wi-Fi(またはイーサネット) → ネットワーク プロファイルの種類を「プライベート」にしてください

### 2. iPhoneで開く

1. PCのブラウザで `http://localhost:8000/setup` を開きます（QRコードが出ます。コンソールのQRでも可）
2. iPhoneのカメラでQRを読み、Safariで開きます。トークンは自動で保存されます
   - QRのURLは `http://<PC名>.local:8000/…`。Windows 10 以降は PC名.local の問い合わせ（mDNS）に標準で応答するので、DHCPでIPが変わってもそのまま使えます
3. 共有ボタン →「ホーム画面に追加」しておくと、次からはアイコン1タップで開けます
4. 「写真・ファイルを選ぶ」→ 選んで「送信」

タイトルの下が「接続OK: PC名」になっていれば通信できています。

- 右上の **↻** で再読み込み（ホーム画面から開いた Web アプリには再読み込みの操作が無いため）
- 右上の **⚙** にバージョン・接続先・**接続用のQRコード**と「トークンを入れ直す」があります。QR を家族の iPhone のカメラで読めば、PC の前に行かなくても接続を設定できます（誤操作しないよう普段は隠しています）。ページ下にもバージョンを表示

> Safari の写真選択から送ると、iOS が HEIC を **JPEG に自動変換**して送ることが多いです（設定やiOSのバージョンによる）。
> ショートカットから送った場合は元の HEIC のまま届きますが、PC側で JPEG に変換します（下記）。

### 常駐（タスクトレイ）

`start_tray.bat` で起動すると、通知領域に青い ⬇ アイコンが出ます。右クリックのメニュー：

| メニュー | 内容 |
|---|---|
| 受信フォルダを開く | 最後に受信したフォルダ（アイコンの左クリックでも同じ） |
| 保存先を開く | `save_dir` そのもの |
| ビューアーを開く | 「PCで表示」用のビューアーウィンドウを開く |
| 最近のテキスト | iPhone から届いたテキスト（最新10件・再起動で消える）。選ぶともう一度コピー |
| 画像が1枚だけ届いたとき：クリップボードにコピー | チェックで ON/OFF（`single_image_clipboard`） |
| 画像が1枚だけ届いたとき：すぐ開く | チェックで ON/OFF（`single_image_open`）。フォルダの代わりに画像を開く |
| iPhone接続用QRを表示 | `http://localhost:8000/setup` をブラウザで開く |
| Windowsログイン時に起動 | チェックでスタートアップにショートカットを置く／外すと消す |
| ログを開く | `landrop.log`（受信の記録とエラー） |
| 再起動 | 常駐を起動し直す（config.toml を手で直したときや、更新を反映したいとき） |
| 終了 | 常駐をやめる |

アイコンにマウスを乗せると最終受信の時刻と件数が出ます。チェック項目の変更は `config.toml` にも書き戻すので、再起動しても残ります。

### テキスト共有

- **iPhone → PC**：ページの「テキスト」欄に貼り付けて「PCへ送る」。PC の画面右下に**プレビューの窓**が出ます
  - PC のクリップボードは勝手に書き換えません。窓の「**クリップボードにコピー**」を押したときだけコピーします（Enter でも可。Esc で閉じる、←→ でボタン移動）
  - 内容が URL だけなら「ブラウザで開く」ボタンも付きます
  - 窓は他のウィンドウの手前に出ますが、作業中のキー入力は奪いません（キーで操作するときは窓を一度クリック）
  - 以前のように自動でクリップボードへ入れたいときは `text_popup = false` / `text_to_clipboard = true`
  - Safari で見ているページを送るなら、ショートカット「テキストをPCへ」（下記）を共有シートから使うのが早い
- **PC → iPhone**：ページの「PCから取得」で、PC のクリップボードにある文字を受け取ります。URL なら「開く」リンクも出ます
  - HTTP のページなので iPhone のクリップボードへ自動コピーできないことがあります。そのときは欄を長押ししてコピー。ショートカット「PCのテキストを取得」なら確実にクリップボードへ入ります
  - PC のクリップボードを読ませたくなければ `share_pc_clipboard = false`

### PCで表示（iPhone をリモコンにする）

「PCで表示」に写真・動画のサムネイルが並び、タップすると PC の画面に大きく映ります（◀ ▶ で前後）。

- 上のプルダウンで候補を切り替えられます：**直近**・**一つ前**（`直近（13:05・8件）`）と、PC の**日付フォルダ**（`10/17（25）`、新しい順）
  - 送った直後は「直近」が選ばれます。このページから送ったものは手元の実物をサムネイルに使うので、動画も絵が出ます
- 受信フォルダのサムネイルは PC 側で縮小して送ります（保存先には何も書きません）。動画はサムネイルを作れないので名前だけ表示

- PC 側は専用のビューアーウィンドウに表示します。開いていなければ最初のタップで自動で開きます（トレイの「ビューアーを開く」でも開けます）
  - 中身は Edge のアプリモード（`msedge --app=http://localhost:8000/viewer`）。タブやアドレスバーの無い窓になります。Edge が見つからなければ既定のブラウザのタブで開きます
- ビューアーは常に1つだけ有効です。新しく開いたものに映り、古いものは「別のウィンドウで表示中」と出して止まります（クリックするとそちらに戻せます）
- 有効なビューアーが裏に隠れていたり最小化されていたりするときは、見えている別のビューアーに切り替えます。見えているものが無ければ新しく開きます
- ビューアーのキー操作：**← →** で前後（iPhone に並んでいる順）、**Delete** で表示中のファイルを**ごみ箱へ**（確認ダイアログは SweetAlert2。←→ でボタン移動・Enter で決定・Esc でやめる。HEIC から変換したものは `_heic` の元ファイルも一緒に）。ごみ箱の無いドライブ（ネットワークドライブなど）では削除しません
- ビューアーはダブルクリックで全画面。動画は再生バー付きで再生します（音声付きの自動再生がブラウザに止められたときは消音で再生）
- ビューアーは PC 本体からしか開けません。常駐を再起動しても、開いたままのビューアーは自動で繋ぎ直します

### 画像が1枚だけ届いたとき

スクショを1枚送って、そのまま資料に貼るような使い方向けです（2秒以内にまとめて届いたのが画像1枚だけのとき。HEIC は JPEG 変換後）。

- **クリップボードにコピー**：届いた画像をクリップボードに入れます。Ctrl+V で貼れます（Office やブラウザには透過も保った PNG、その他のアプリにはビットマップで）
- **すぐ開く**：受信フォルダの代わりに画像そのものを既定のアプリ（フォトなど）で開きます

### 受信フォルダ・通知・HEIC変換

- **日付フォルダ**：`保存先\2026-10-17\` のように日付ごとのフォルダに入れます
  - 以前は受信ごとにフォルダを作っていましたが、増えすぎて選びにくかったので日付ごとにしました
  - 直近の受信（どのファイルが何回目に届いたか）は保存先の隠しファイル `.landrop_recent.json` に覚えていて、再起動しても「直近」「一つ前」で選べます
  - 受信が `session_gap_sec`（既定60秒）途切れたら、次の受信は別の回です。大きな動画を受信中に次のファイルが来ても同じ回のまま
  - 以前の受信ごとのフォルダ（`2026-10-17_130544`）は `python tools/merge_legacy_folders.py` で日付フォルダにまとめられます（`--apply` を付けるまでは確認だけ）
- **同じ日に同じファイル**：中身が同じファイルが同じ日付フォルダに既にあれば、新しくは保存せず、既存のファイルを「直近」の履歴に記録します（名前が違っても中身で判定。HEIC は変換後の JPEG を使う）
- **フォルダを開く**：受信が一段落（最後の受信から2秒）すると、日付フォルダを Explorer で開き、今回の1枚目を選んだ状態にします。同じ回は1回だけ開き、追加で届いても窓は増やしません
  - Windows の制限で、Explorer が他の窓の裏に開くことがあります（通知のクリックでも開けます）
- **通知**：受信が一段落すると Windows の通知が1通出ます（10枚送っても1通にまとめる）。クリックすると受信フォルダが開きます
  - 通知の差出人は「Python」と表示されます。出ないときは Windows の 設定 → システム → 通知 で Python と「応答不可」を確認
- **HEIC→JPEG**：`.heic` / `.heif` を受け取ると、同じ名前の `.jpg` を作ります
  - 向き（回転）は画素に反映済み、撮影日時などの EXIF とカラープロファイルは引き継ぎます
  - 元の HEIC は保存先の `_heic` フォルダに移します（`heic_keep_original = false` なら削除）
  - 変換に失敗したときは HEIC のまま残します

## iOSショートカット

共有シートの「PCへ送る」から、写真アプリやファイルアプリで選んだものを直接送れるようにします。
必要な値は PC の `http://localhost:8000/setup` に出ています。

| 項目 | 値 |
|---|---|
| URL | `http://<PC名>.local:8000/api/upload` |
| 方法 | POST |
| ヘッダー | `X-LanDrop-Token` = トークン |
| 本文 | フォーム。キー `files`、種類「ファイル」 |

### 組み方（共有シートから送る）

1. 「ショートカット」アプリ → 右上の「＋」で新規作成。名前を「PCへ送る」にする
2. 下部の ⓘ（詳細）→「共有シートに表示」をオン
   - 先頭に「入力を受け取る」が現れるので、種類を **画像** と **ファイル**（必要なら メディア）にする
   - 「入力がない場合」は「写真を選択」にしておくと、ホーム画面から起動したときも使える
3. アクション **「繰り返す（各項目）」** を追加。対象は「ショートカットの入力」
4. 繰り返しの中に **「URLの内容を取得」** を追加し、次のように設定
   - URL：`http://<PC名>.local:8000/api/upload`（`/setup` に出ている値をコピー）
   - 「表示を増やす」を開く
   - 方法：**POST**
   - ヘッダー：「新規ヘッダーを追加」→ キー `X-LanDrop-Token`、値にトークン
   - 本文を要求：**フォーム** →「新規フィールドを追加」→ **ファイル** → キー `files`、値に変数 **「繰り返し項目」**
5. 繰り返しの外（「繰り返しの終了」の後）に **「通知を表示」** を追加し、「送信しました」など
6. 写真アプリで写真を選び → 共有 →「PCへ送る」で動作確認

1ファイルずつ送るのは、途中で失敗してもどれが届いたか分かりやすくするためです（フォームのファイル欄に複数項目を一度に入れる方法は、iOSのバージョンで挙動が揺れます）。

### テキスト用のショートカット

**「テキストをPCへ」**（Safari の共有シートから URL を送る・クリップボードの文字を送る）

1. 新規作成 → ⓘ →「共有シートに表示」をオン。入力の種類は **テキスト** と **URL**、「入力がない場合」は **クリップボードを取得**
2. **「URLの内容を取得」**
   - URL：`http://<PC名>.local:8000/api/text`
   - 方法 **POST**、ヘッダー `X-LanDrop-Token` = トークン
   - 本文を要求：**JSON** →「新規フィールドを追加」→ **テキスト** → キー `text`、値に **「ショートカットの入力」**
3. **「通知を表示」**：「PCへ送りました」

**「PCのテキストを取得」**（PC でコピーした文字を iPhone のクリップボードへ）

1. **「URLの内容を取得」**：URL `http://<PC名>.local:8000/api/text/pc`、方法 **GET**、ヘッダー `X-LanDrop-Token` = トークン
2. **「辞書の値を取得」**：キー `text`（辞書は1の「URLの内容」）
3. **「クリップボードにコピー」**：2の「辞書の値」
4. **「通知を表示」**：「辞書の値」を本文に入れると、何が入ったか分かる

どちらもホーム画面に置いたり、設定 → アクセシビリティ → タッチ →「背面タップ」に割り当てたりすると1アクションで使えます。

### うまくいかないとき

- **何も起きずタイムアウトする**：iPhoneとPCが同じWi-Fiか／PCのファイアウォールとネットワークプロファイル（上記）を確認
- **401**：トークンの写し間違い。前後の空白にも注意
- **初回に「ローカルネットワーク上のデバイスの検出と接続を許可」**が出たら許可する（設定 → プライバシー → ローカルネットワーク → ショートカット）
- **`.local` の名前で届かない**：`/setup` に出ている IP の URL で試す。IP は変わることがあるので、その場合はルーターの DHCP 予約で PC の IP を固定し、`advertise_host = "ip"` にする

### 別解：ファイル本文で送る（`/api/upload/raw`）

フォームを使わず、本文にファイルそのものを入れる方式です。

- URL：`http://<PC名>.local:8000/api/upload/raw?filename=` の後ろに変数「名前」（＋拡張子）
- 方法：POST、ヘッダーは同じ、本文を要求：**ファイル** → 送るファイル
- ファイル名は `?filename=` か `X-Filename` ヘッダー（URLエンコード可）。無ければ `landrop_日時.拡張子` になる

## API

すべて `/api/` 以下はトークン必須です。ヘッダー `X-LanDrop-Token: <token>` か `Authorization: Bearer <token>`。

| メソッド | パス | 内容 |
|---|---|---|
| GET | `/` | アップロードページ（認証なし。トークンは `#t=` で渡しブラウザに保存） |
| GET | `/api/ping` | 疎通・トークン確認 `{"app","version","host"}` |
| POST | `/api/upload` | multipart/form-data、フィールド `files`（複数可） |
| POST | `/api/upload/raw` | 本文＝ファイル1つ。`?filename=` または `X-Filename` |
| POST | `/api/text` | テキストを PC へ。JSON `{"text": "..."}` か本文そのもの（text/plain）。1MB まで |
| GET | `/api/text/pc` | PC のクリップボードの文字 `{"text": "..."}`（`share_pc_clipboard = false` なら 403） |
| GET | `/api/folders` | 写真・動画のある受信フォルダ（新しい順）`{"folders": [{"name", "label", "count"}]}` |
| GET | `/api/folder?name=` | フォルダの中の写真・動画（受信順）`{"items": [{"id", "name", "kind"}]}` |
| GET | `/thumb/{id}` | 画像のサムネイル（320px の JPEG）。id は上の一覧でしか渡さない推測できない値なのでトークン不要 |
| POST | `/api/show` | 受信したファイルをビューアーに映す。JSON `{"id": "...", "ids": [並んでいる一覧]}`（ids はビューアーの ←→ 用） |
| GET | `/api/qr` | 接続用の QR コード（SVG。中身はトークン入りの URL） |
| GET | `/setup` | QRとトークンの案内（PC本体＝localhostからのみ） |
| GET | `/viewer` | PC 側ビューアー。`/viewer/events`（SSE）で切り替えを受け取る（localhostのみ） |

応答例：`{"saved": [{"name": "IMG_0001.JPG", "size": 2483021, "id": "3f2a9c01b7de"}]}`
同名ファイルは上書きせず `IMG_0001 (1).JPG` のように番号を付けます。

curl で試す：

```bash
curl -H "X-LanDrop-Token: <token>" -F "files=@photo.jpg" http://localhost:8000/api/upload
```

## 設定（config.toml）

`config.example.toml` と同じ形式です。`config.toml` はトークンを含むので Git には入れません。

| キー | 既定値 | 説明 |
|---|---|---|
| `token` | 自動生成 | 漏れたら `""` にして再起動すると作り直される（iPhone側はQRを読み直す） |
| `save_dir` | `~/Downloads/LanDrop` | 保存先。`~` や `%USERPROFILE%` 可 |
| `host` / `port` | `0.0.0.0` / `8000` | 待ち受け |
| `max_file_mb` | `1024` | 1ファイルの上限（超えたら 413、書きかけは消す） |
| `advertise_host` | 空 | QR・案内に載せるアドレス。空＝`PC名.local`、`"ip"`＝現在のIP、それ以外はその値 |
| `date_folders` | `true` | 日付フォルダに入れ、直近の受信を覚える |
| `session_gap_sec` | `60` | この秒数途切れたら次の受信は別の回（「直近」「一つ前」の区切り） |
| `open_folder` | `true` | 受信が一段落したらそのフォルダを Explorer で開く |
| `single_image_clipboard` | `true` | 画像1枚だけ届いたらクリップボードにも入れる（トレイで切替） |
| `single_image_open` | `false` | 画像1枚だけ届いたらフォルダの代わりに画像を開く（トレイで切替） |
| `text_popup` | `true` | 届いたテキストを PC の窓でプレビュー（コピーはボタンで） |
| `text_to_clipboard` | `false` | 届いたテキストを PC のクリップボードへ自動で入れる |
| `share_pc_clipboard` | `true` | iPhone から PC のクリップボードの文字を取得できる |
| `notify` | `true` | 受信時のWindows通知 |
| `heic_to_jpeg` | `true` | HEIC/HEIF を JPEG に変換 |
| `heic_keep_original` | `true` | 変換元の HEIC を `_heic` フォルダに残す |
| `jpeg_quality` | `92` | 変換後 JPEG の画質（1〜95） |

設定を変えたらサーバーを再起動してください（トレイのチェック項目は即時反映）。

## 構成

```
landrop/
  __main__.py   起動（python -m landrop）。案内表示とQR
  config.py     config.toml の読み込み・初回生成
  server.py     FastAPI アプリ。認証ミドルウェア・各エンドポイント
  storage.py    保存（ファイル名の無害化・重複回避・上限・.part→確定）、日付フォルダと直近の受信の記録、同じ日の同じファイルの判定
  hooks.py      受信後処理の差し込み口。build_hooks() が設定に応じて組み立てる
  heic.py       HEIC→JPEG（transform フック）
```

## 今後の機能と、そのための設計

受信後処理は `hooks.py` の2種類のフックで足します（HEIC変換・通知・フォルダを開くは実装済み）。

- **transform**：保存直後・応答前に1ファイルずつ呼ばれ、差し替えた `ReceivedFile` を返せる（`heic.py`）
- **listener**：1リクエスト分の受信が終わった後、応答とは別にバックグラウンドで呼ばれる（`notify.py`）

| 機能 | 差し込む場所 | メモ |
|---|---|---|
| HTTPS（自己署名） | `__main__.py` の `uvicorn.run(ssl_certfile=…)` と `server.setup_url` | 設定キー `https` / `cert_file` / `key_file` は予約済み。iPhone に証明書（プロファイル）を入れて信頼させる手順が必要 |
| mDNS サービス広告 | 新規 `discovery.py`、起動時に登録 | `PC名.local` での名前解決は Windows 標準の応答で足りているので現状不要。専用アプリから一覧で見つけたくなったら `_landrop._tcp` を `zeroconf` で広告する |

- 認証とサイズ上限は ASGI ミドルウェア（`GuardMiddleware`）で、**本文を読む前に**判定しています（FastAPIは依存関係より先にフォームをパースするため）
- 保存は `保存先/.xxxx.part` に書いてから本来の名前へ rename。受信途中や上限超過で失敗したファイルが中途半端に残りません
